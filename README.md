# SayPrint Website

Modern textile services website built with Vite.

## Development

1.  Install dependencies:

    ```bash
    npm install
    ```

2.  Run development server:
    ```bash
    npm run dev
    ```

## Building for Production

1.  Build the project:

    ```bash
    npm run build
    ```

2.  Preview the build:
    ```bash
    npm run preview
    ```

## Hosting

The output in `dist/` is a static site ready for deployment on:

- Netlify
- Vercel
- GitHub Pages
- Any standard web host

## Updates

- **Content**: Edit `index.html` or `contact.html`.
- **Styles**: Edit `src/style.css`.
- **Images**: Place in `src/assets/`.
